# AI小学学习系统 V2.4 · 间隔复习系统（Spaced Repetition & Forgetting Risk Engine）

> V2.3 解决了"学什么、出多难、下一题是什么"；
> V2.4 解决"**学会了之后怎么不忘**"：
>
> ```text
> 学会 → 巩固 → 防止遗忘 → 长期掌握
> ```
>
> 每个学生 × 每个科目 × 每个知识点都有**独立的记忆状态**（`knowledge_memory_state`），
> 系统据此判断：还记不记得 → 有多大概率忘了 → 下次什么时候复习 → 这次出几题 → 出什么题。
>
> V2.0~V2.3 的能力全部保留，本版本只做加法（老库自动升级，不删数据）。

## 二、记忆状态模型 `knowledge_memory_state`

一个学生 + 一个科目 + 一个知识点一行，**学生之间、科目之间、知识点之间完全独立**。

| 字段 | 含义 |
| --- | --- |
| `mastery_score` | 0~100 知识理解与掌握（沿用 MasteryEngine 的结果） |
| `memory_strength` | 0~100 当前记忆强度 |
| `stability` | 记忆稳定性（天）：越大越耐忘，允许更长间隔 |
| `difficulty` | 0~1 **这个学生在这个知识点上的个人难度**（不是知识点固定难度） |
| `review_count` / `successful_reviews` / `failed_reviews` | 复习次数、成功次数、失败次数 |
| `last_learned_at` / `last_reviewed_at` / `next_review_at` | 学会时间、最近复习时间、下次复习时间 |
| `current_interval_days` | 当前复习间隔（天） |
| `forgetting_risk` | 0~1 遗忘风险（0.15 低 / 0.55 中 / 0.85 高） |
| `maturity_level` | NEW / LEARNING / SHORT_TERM / CONSOLIDATING / STABLE / LONG_TERM |
| `needs_relearn` | 掌握度 <60 或连续复习失败 → 交给自适应引擎重新学 |
| `consecutive_failures` / `review_streak` | 连续失败 / 连续成功次数 |

记忆强度公式：

```text
base   = 0.55 × 掌握度 + 0.45 × 稳定性分（稳定性分 = 100 × ln(1+s)/ln(91)）
strength = base × (0.6 + 0.4 × (1 − 遗忘风险))
```

个人难度公式：

```text
difficulty = 0.5 + (70 − 掌握度)/100 + 0.08 × 失败次数 − 0.03 × 成功次数
             （最近一次答错再 +0.08，夹到 0.1~0.9）
```

### 成熟度六级（儿童端不显示英文）

| 后端 | 家长端 | 儿童端 | 知识森林（V2.6 预留） |
| --- | --- | --- | --- |
| `NEW` | 刚接触 | 🌱 刚学会 | 🌰 种子 |
| `LEARNING` | 正在学习 | 🌱 刚学会 | 🌱 幼苗 |
| `SHORT_TERM` | 短期掌握 | 🌿 正在巩固 | 🌿 小树 |
| `CONSOLIDATING` | 巩固中 | 🌿 正在巩固 | 🌳 成长树 |
| `STABLE` | 稳定掌握 | 🌳 记得很牢 | 🌲 大树 |
| `LONG_TERM` | 长期掌握 | ⭐ 长期掌握 | ⭐ 星光树 |

判定规则（单调、可解释）：

```text
掌握度 <60 或 needs_relearn           → LEARNING（练过）/ NEW（没练过）
掌握度 <70                            → LEARNING
稳定性 ≥60 且 掌握度 ≥85 且 成功复习 ≥5 → LONG_TERM
稳定性 ≥21 且 掌握度 ≥80              → STABLE
掌握度 ≥85                            → STABLE（迁移来的老数据）
稳定性 ≥7 或 成功复习 ≥2              → CONSOLIDATING
其它                                  → SHORT_TERM
```

## 三、自适应间隔算法 `calculate_next_interval()`

"**阶梯起步 + 稳定性驱动**"两段式，不是机械照抄艾宾浩斯曲线。

```text
初始学习成功            → 1 天后复习
第 1 次复习成功（GOOD） → 3 天
第 2 次                 → 7 天
第 3 次                 → 14 天
第 4 次                 → 30 天
之后                    → 按稳定性动态扩大（最长 180 天）
```

复习质量（`review_quality`）与乘数：

| 质量 | 判定（自动） | 间隔乘数 | 阶梯加成 | 稳定性变化 |
| --- | --- | --- | --- | --- |
| `AGAIN` | 答错 | ×0.35 | 直接压缩 | ×0.45 |
| `HARD` | 答对但用时 > 1.5 倍期望，或自评"有点难" | ×1.0 | ×0.7 | +25% |
| `GOOD` | 答对且正常 | ×1.4 | ×1.0 | +50% |
| `EASY` | 答对且用时 < 一半期望，或自评"简单" | ×1.8 | ×1.5 | +90% |

稳定性驱动阶段的其它因子：

| 因子 | 规则 |
| --- | --- |
| 掌握度 | ≥85 ×1.15 / 70~84 ×1.0 / 60~69 ×0.85 / <60 ×0.7 |
| 个人难度 | × (1 − 0.3 × difficulty) |
| 稳定性 | × (1 + 0.15 × min(1.5, stability/30)) |
| 答题速度 | 更快 ×1.1 / 更慢 ×0.9 |
| 学生自评 | 简单 ×1.1 / 有点难 ×0.9 |
| 置信度 | 题量少（<0.4）× 0.8 |

约束：间隔恒在 **1~180 天**；稳定性驱动阶段还限制"间隔 ≤ 新稳定性 × 3"。
函数返回 `next_interval`、`next_review_at`、`new_stability` 与 `factors` / `reason`（写进策略日志）。

实测序列：

| 情形 | 间隔序列（天） |
| --- | --- |
| 连续 GOOD | 1 → 3 → 7 → 14 → 30 → 43 |
| 连续 EASY | 1 → 5 → 11 → 21 → 45 → 84 |
| 连续 HARD | 1 → 2 → 5 → 10 → 21 |
| 复习失败（AGAIN，当前 7 天） | 7 → 2 |

## 四、遗忘风险模型 `ForgettingRiskEngine`

```text
overdue     = 距上次复习天数 / 原定间隔天数        （>1 表示已逾期）
time_risk   = overdue / (overdue + 0.35)
risk        = time_risk
              × 稳定性因子     1 / (1 + 0.08 × ln(1 + stability))
              × 掌握度因子     1.3 − 0.5 × mastery/100   （夹到 0.75~1.3）
              × 个人难度因子   1 + 0.3 × difficulty
              × 历史成功率因子 1.2 − 0.4 × success_rate
              × 上次表现因子   上次失败 ×1.2
              × 成熟度因子     LONG_TERM ×0.8 / STABLE ×0.9
```

分级：`≥0.75` **高**（快要忘了）、`≥0.45` **中**（该复习了）、其余 **低**。

实测：某知识点上次复习在 10 天前、原定 7 天、稳定性 3 → 风险 **0.79（高）**，自动进今日队列。

风险刷新是**增量的**：只有"变化超过 0.05"或"已经到期"的记录才写库，页面刷新不会重算全表。

## 五、今日复习队列 `ReviewScheduler`

| 优先级 | 条件 | 说明 |
| --- | --- | --- |
| `P0` | 已超过 `next_review_at` | 到期了，必须复习 |
| `P1` | `forgetting_risk ≥ 0.75` | 还没到期，但快忘了 |
| `P2` | 最近 3 天刚学会、成熟度还低 | 早期巩固 |
| `P3` | 被依赖度高（基础）且 `risk ≥ 0.5` | 基础不能塌 |

三条限流：

1. 每科最多 **8 个**知识点；
2. 每天最多 **15 个** → 超出的**顺延到后面几天**（长期没登录也不会一次安排 100 个任务）；
3. 每个知识点 **1~3 题**：风险 ≥0.75 出 3 题、≥0.5 出 2 题、其余 1 题。

`needs_relearn` 的知识点**不进复习队列**，单独返回给自适应引擎重新学（RELEARN）。

队列按天缓存在 `review_queue` 表：同一天第二次打开页面直接读，不重新调度（性能要求），
只有 `?refresh=true` 才重排。

## 六、复习题选择 `ReviewQuestionSelector`

**复习题不能简单重复原题**，否则考的是"记住答案"而不是"掌握知识"。

| 模式 | 普通知识点 | 长期掌握 | 说明 |
| --- | --- | --- | --- |
| `same` | 50% | 20% | 同知识点、换数字/换题 |
| `variant` | 30% | 40% | 变式题（换表达、换情境） |
| `transfer` | 20% | 40% | 迁移题（结合前后知识点、略高一个阶段） |

出题优先级：

1. **AI**（配了 Key）：prompt 里带上历史原题与"不要重复、要换数字或情境"的硬约束
2. **本地题库/生成器**（`diagnostic_bank`）：数学按阶段随机生成新数字，语文/英语从题库轮换
3. **兜底变式**：内置题换数字 + 答案重算

重复检测：题干完全相同，或"数字序列相同且文字相似度 ≥0.9" → 判为重复，换一道再来（最多 3 轮）。
换数字（`36 × 24` → `42 × 18`）不会被误判为重复，因为它考的是同一个知识核心。

## 七、复习失败处理（与错题康复系统连接）

```text
复习答错
  ├── 间隔压缩（×0.35）、稳定性 ×0.45
  ├── 写 AnswerRecord → 错因分析 → 错题本（与日常练习完全同一套）
  └── 若原来是 STABLE / LONG_TERM 且只是偶尔错 1 题
        → 不推翻结论，追加 1 道验证题（need_verify=true）

连续失败 2 次 或 掌握度 <60
  → 确认遗忘 → needs_relearn=true
  → 成熟度降到 LEARNING、间隔压到 1 天
  → 进入 RELEARN（交回 AdaptiveLearningEngine 重新学）
  → 重新学会后再从 1 天开始复习
```

长期错题经过多轮复习成功 → `wrong_questions.status` 走到 `MASTERED`，转入长期记忆维护。

## 八、每日学习内容配比 `calculate_daily_mix()`

| 内容 | 默认 | 动态调整 |
| --- | --- | --- |
| `new_learning` 新学 | 50% | 没有能力画像时降到 0（先补强与复习） |
| `weakness` 薄弱补强 | 30% | 没有薄弱知识点时让给新学 |
| `review` 间隔复习 | 20% | 无复习任务 → 5%；≤2 个 → 10%；高风险 ≥3 个或平均风险 ≥0.6 → **40%**；有 RELEARN → 一半额度转给补强 |

比例归一化到合计 1.0，再按科目题量拆分（`split_counts`）。
某一类今天没内容时，额度自动补给其它类，避免"计划 10 题只排了 9 题"。

`/api/learning/plan` 的每个条目都带 `item_type`（`new_learning` / `weakness` / `review`）与 `item_type_text`，
计划总览还返回 `by_type` 汇总。

## 九、与 V2.3 自适应引擎的衔接

```text
AdaptiveLearningEngine
  ↓ 读取：能力阶段 / 掌握度 / 错因历史 / 遗忘风险（MemoryState）/ 今日复习队列
  ↓ 生成：今日计划（新学 + 薄弱补强 + 间隔复习）
  ↓ 推荐时优先判断：是否有到期复习任务（review_first）
```

- `adaptive/engine.profile()` 会把记忆状态并进画像：`forgetting_risk`、`memory_stability`、`maturity_level`、`needs_relearn`
- `adaptive/strategy.forgetting_risk()` 优先使用实测风险（没有记忆状态时才用时间估算）
- `GET /api/learning/recommend/{id}` 返回 `review` 段、`daily_mix`、`review_first`
- `POST /api/learning/start` 返回 `review_first` 与 `review` 提示（前端可提示"先复习再学新的"）

## 十二、数据库迁移（V2.3 → V2.4）

**不删任何 V2.3 数据**。升级步骤：

1. 直接启动（`start.bat`）：`create_all` 自动建 4 张新表，`ensure_schema` 自动给 `learning_plan` 补 `item_type` 列；
2. 启动时调用 `review.engine.ensure_states()`，按 `student_knowledge_mastery` 初始化记忆状态（幂等，重复启动不会重复搬）：

| V2.3 掌握度 | 初始成熟度 | 初始间隔 | 初始稳定性 |
| --- | --- | --- | --- |
| ≥85 | `STABLE` | 14 天 | 21 |
| 70~84 | `CONSOLIDATING` | 7 天 | 7 |
| 60~69 | `LEARNING` | 3 天 | 3 |
| <60 | `LEARNING` + `needs_relearn`（RELEARN） | 1 天 | 1 |

3. 迁移过来的知识 `next_review_at = 现在`，所以升级当天就会进队列"先看一眼"，不会凭空丢失记忆；
4. 旧的 `student_knowledge_mastery`、`reviews`、`wrong_questions` 全部保留，V2.1 艾宾浩斯复习面板照旧可用。

## 十三、边界情况

| 边界 | 处理 |
| --- | --- |
| 新用户没有任何复习数据 | 队列为空，儿童端提示"今天的知识都很健康"；先诊断/练习，首次学会后 1 天进入复习 |
| 长期没登录（例如 60 天后回来） | 队列每天最多 15 个，其余自动顺延到后面几天（`deferred` + 队列落库） |
| 一个知识点长期没练 | 遗忘风险随时间上升 → P1 进队列；风险 ≥0.75 直接安排 |
| 掌握度很高但置信度低 | 间隔 ×0.8，先短间隔确认（题量少不能给高置信） |
| 掌握度低于 60 | 不做纯复习，返回 `RELEARN` 交给自适应引擎重新学 |
| 长期掌握的知识偶尔错 1 题 | 不重置结论：只压缩间隔、降稳定性，并追加 1 道验证题 |
| 连续错 2 次 | 确认遗忘 → `needs_relearn` → RELEARN → 重新学 → 短周期复习 |
| 复习题可能重复 | AI 带历史题约束 + 本地换数字/换题 + 生成后重复检测（最多 3 轮） |

## 十四、性能

- 风险刷新是增量的（变化 <0.05 且未到期不写库）；
- 每日队列按天缓存（`review_queue` 唯一键：学生 + 日期 + 科目 + 知识点），当天重复打开不重排；
- 记忆状态查询按 `(student_id, subject)` 索引；本机两个学生 + 数百条记忆状态毫秒级响应。
