# AI小学学习系统 V2.1

在 V2.0「自适应难度」闭环之上，V2.1 增加两件事：

1. 同一个知识点按**艾宾浩斯遗忘曲线**安排复习，答错的当天再练，答对的间隔逐步拉长。
2. 题目和解析支持**语音朗读**，小朋友可以不看字先听懂题目。

---

## 一、艾宾浩斯记忆曲线

### 1. 复习间隔阶梯

`backend/srs.py` 里的 `INTERVALS` 是复习间隔表，单位统一用秒：

| 阶段 | 间隔 | 说明 |
| --- | --- | --- |
| 0 | 5 分钟 | 刚学完的第一次强化（答错也回到这一级） |
| 1 | 30 分钟 | |
| 2 | 12 小时 | 当天睡前再来一次 |
| 3 | 1 天 | |
| 4 | 2 天 | |
| 5 | 4 天 | |
| 6 | 7 天 | |
| 7 | 15 天 | |
| 8 | 30 天 | |
| 9 | 60 天 | |
| 10 | 120 天 | 满级即视为长期掌握 |

### 2. 升级与降级规则

- **答错**：阶段直接打回 0，5 分钟后再练一遍这个知识点。
- **答对**：连续答对 3 次（`STREAK_TO_ADVANCE`）才升一级，避免"蒙对一次就拉长间隔"。
- **掌握**：升到第 10 级后标记为已掌握，不再进复习队列。
- **掌握度**：按当前阶段换算成百分比（阶段 1 = 9%，阶段 10 = 91%），给小朋友一个直观进度。

### 3. 出题时怎么用到复习计划

`GET /question` 的顺序是：

1. 先按页面填写的「知识点」确定本次要练什么（家长/孩子手动选择优先，避免被复习任务抢走）。
2. 同时把该学生、该科目下所有到期的知识点整理成**复习面板**返回给前端。
3. 返回 `review`（当前知识点的阶段、掌握度、下次复习时间）与 `due_reviews`（还有哪些知识点该复习）。

前端会在题目上方显示「🔁 艾宾浩斯复习 · 第 N 阶段 · 掌握度 X%」徽标，
以及一个「⏰ 还有 N 个知识点到期该复习了」面板，点「立即复习」即可切到那个知识点。

`GET /reviews?student_id=1&subject=数学` 返回完整的复习总览（阶段、掌握度、下次复习时间、正确率），
供后续做「学习报告 / 家长端」时直接使用。

### 4. 数据表

`reviews` 表由 `Base.metadata.create_all` 自动创建，老库通过 `ensure_schema` 自动补列，无需手工迁移：

| 字段 | 含义 |
| --- | --- |
| student_id / subject / knowledge | 哪个学生的哪个知识点 |
| stage | 当前复习阶段（等于间隔表长度即已掌握） |
| interval | 当前复习间隔（秒） |
| streak | 当前阶段内连续答对次数 |
| review_count / correct_count | 累计作答次数与正确次数 |
| last_result | 最近一次是否答对 |
| next_review_at | 下次复习时间 |

## 二、语音朗读

前端使用浏览器内置的 Web Speech API（`speechSynthesis`），不依赖任何付费服务。

- **自动读题**：题目生成后自动朗读题干，选择题会依次念出 A/B/C/D 选项。
- **读解析**：作答后点「🔊 读解析」即可听正确答案与讲解。
- **静音开关**：「🔊 语音读题」勾选框可随时关闭，设置写入 `localStorage`，下次打开仍然生效。
- **语速**：很慢 / 慢 / 正常三档，同样会记忆。
- **中文音色**：优先挑选系统里的中文语音（如 Microsoft Huihui/Xiaoxiao），找不到时回退到系统默认音色并给出提示。
- **口语化处理**：朗读前会把符号换成中文读法，避免机器读出怪音：
  `____ → 空格`、`× → 乘`、`÷ → 除以`、`＋ → 加`、`＝ → 等于`、`？ → 句号停顿`。

> 说明：语音功能依赖系统已安装的中文语音包。Windows 上如果听不到声音，
> 可在「设置 → 时间和语言 → 语音」里添加中文语音。

## 三、自测

统一入口（推荐，三个套件串行跑完，各用独立端口，都不需要外网）：

```bash
python backend/verify_all.py            # 全部
python backend/verify_all.py review web # 只跑指定套件
```

| 套件 | 内容 | 是否需要先起后端 |
| --- | --- | --- |
| `review` | 艾宾浩斯复习闭环（临时后端 + 临时库） | 不需要 |
| `flow` | 原有学习闭环回归（临时后端 + 临时库） | 不需要 |
| `web` | 前端语音与复习面板逻辑（DOM 打桩跑真实 app.js） | 不需要 |

也可以单独跑：

```bash
python backend/verify_review.py              # 端口 8899，可用 VERIFY_REVIEW_PORT 改
python backend/verify_flow.py --self-serve   # 端口 8900，自拉临时后端 + 临时库
python backend/verify_flow.py                # 不带参数则连 127.0.0.1:8000（需先起后端）
node frontend/verify_web.js
```

说明：

- 两个 Python 套件在启动前都会检查端口，被占用时立刻报错退出，不会连上别人的服务跑出"假通过"。
- 退出时都会收掉临时后端进程、释放数据库连接并删除临时库，不会留下占用端口的残留进程。
- 出题请求（约 1.3s/次）是整套测试最贵的一步，脚本已经避免在同一个断言场景里重复出题。
